## 分類總表與題號跳轉

總表位於年度複選框之前，依附件 Word 的總表整理：列為年度、數 A／數 B，欄為數學 1、2、3A、4A、3B、4B。保留附件由新到舊的年度順序，共有 331 個冊別與題號連結；110 年未分卷，對照全部六冊。

- 點題號，前往該冊首次收錄此題的單元，並展開所在冊、單元、題目。
- 同題可收錄於多個單元；總表的同一格不重複列出相同題號。
- 若目標年度未勾選，跳轉時會自動勾選該年度。
- 每題的原題前方及詳解後方都有「回總表」，回到該冊、該卷的對應題號，並以底色提示。
- 網址的題目定位可用瀏覽器上一頁、下一頁操作，也可直接分享含定位的網址。
- 窄螢幕的總表可左右捲動；年度欄與表頭固定，方便對照。

## 圖文詳解

全部 468 處單元收錄均改用分步版面，保留各冊、各單元的解法、關聯認列及部分涵蓋說明。150 道原題另附幾何輔助圖、函數圖、數線、機率表或計數整理表；其餘依題意以列式與分步推導呈現。

- 詳解預設收合，標題為「查看本題詳解」。
- 以「本單元怎麼切入 → 圖與條件（需要時）→ 分步詳解 → 提醒 → 答案」呈現。
- 分數使用水平分數線；指數、下標、根號與矩陣以數學排版顯示。
- 新圖為內嵌 SVG；放大後仍保持清晰，無須新增圖片資料夾。
- 參考題 114 年數 A 第 11 題重新繪製角平分線、分點比與面積圖，逐項說明五個選項。
- 空間圖標明斜投影或結構示意，長度與角度以推導計算為準。
- 手機上的長算式與示意圖可各自左右捲動，不會撐寬整個頁面。
- 按首次展開才建立該題的公式與圖形，減少大量收合詳解對捲動和篩選的負擔。

向量以端點字母表示，例如 AB 表示從 A 指向 B，|AB| 表示長度；請配合題目脈絡及文字辨別。關聯或部分涵蓋的收錄仍保留完成全題須結合的單元。110 年第 13 題的複數共軛根部分，沿用原分類的補充知識說明。

## 年度、收摺及閱讀標記

110～115 年預設全選；冊別、單元、題目預設全部展開，詳解預設收合。各層前方有方框「＋／−」，可獨立操作。「全部展開」會展開分類與原題，並收合詳解。

各冊使用不同粉彩底色，冊標題大於單元標題。單元標題為深灰底、白字，冊與單元題數顯示「共 N 題」。同一原題若在同冊多個單元收錄，冊題數沿用單元收錄加總，並非去除重複的原題數。

閱讀標記可切換左右側，並記住選擇；冊別和單元的題數以紅字呈現。寬螢幕標記靠近內容欄、距上緣 20 px，另有保護空間。冊或單元標題上緣超過標記中央時更新顯示。窄螢幕使用獨立頂部區域，題目在其下方捲動。
